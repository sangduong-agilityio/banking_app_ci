# laza_design

The `laza_design` directory contains all the UI design elements for the Laza project. It follows the atomic design pattern, which is a methodology composed of distinct stages working together to create interface design systems in a more deliberate and hierarchical manner.

## Folder Structure
```
laza_design/
  |- core/
  |- ui/
    |- tokens/ 
    |- atoms/ 
    |- foundation/ 
    |- molecules/ 
    |- organisms/ 
    |- templates/ 
```
