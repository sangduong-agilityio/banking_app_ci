# laza

This directory contains the source code for the Laza App. It using manage logic and state in project

### Directory Structure
The project structure is organized based on features. Each feature has its own folder, and layers are organized inside each feature.

```
laza/
├─ lib /
  ├─ core/
  ├─ features/
  │ ├─ home/
  │ │ ├─ repository/
  │ │ │ ├─ home_repository.dart
  │ │ ├─ screen/
  │ │ │ ├─ widget/
  │ │ │ │ ├─ ...
  │ │ │ ├─ home_page.dart
  │ ├─ signin/
  │ ├─ signup/
  │ ├─ etc/
├─ test/(update)
```
